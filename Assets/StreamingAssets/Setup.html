创建你的舞者与动作库

CHOREO AI 使用 Tripo 人物与 Humanoid 骨骼动作。动作可从现成动作库导入；使用这条路径无需 fal 额度。

  1. 在 Mixamo 登录 Adobe 账号，选择舞蹈动作。下载设置：FBX for Unity、Without Skin、30 FPS、Keyframe Reduction: None。
  2. 用 Unity 2022.3.62f3 打开源码项目，停止 Play Mode，进入 Tools → CHOREO AI → Import motion FBX，填写名称、来源和真实舞种标签后导入。Tripo 人物无需上传到动作库。
  3. 在素材工作台检查人物关节、接地和穿插；裁剪真正的一组八拍，校正每个拍点，填写复查记录。
  4. 分别预览并复查需要的动作连接，然后直接在 Unity Play Mode 中导入音乐练习。
  5. 需要交付独立 Windows 程序时，再执行 Tools → CHOREO AI → Build Windows。

生成人物使用 Tripo API；文字生成动作仍可选用 fal。Key 在编辑器的 Generation console 中本地保存，不要发到聊天或放进构建。

FBX 导入在 Unity 编辑器完成。成品使用已打包的素材离线练习，不支持直接导入任意 FBX。先确认少量素材的动作质量，再扩大动作库；全片均分拍点只是预览草稿。
