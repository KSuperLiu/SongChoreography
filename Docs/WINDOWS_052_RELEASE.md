# 0.5.2：重新排列现有动作

0.5.1 的“生成组合”使用固定种子，重复点击会得到完全相同的动作顺序。“换一版”即使改变种子，也可能选到相同结果。0.5.2 将主按钮改为“重新排列现有动作”：比较 32 个确定性候选，优先选择改变片段最多的结果，同等变化量时选择使用种类更多的结果；只采用已审核连接。

界面显示动作库存段数、当前使用种数，完成后显示实际改变的片段数。暂停时会定位到第一个发生变化的片段，便于观察；播放时保持歌曲时钟。“从头演示当前组合”用于从头播放，不会再与重排混淆。锁定和每个时间槽保持不变；全部锁定或找不到不同组合时给出原因，保留原编排和种子。

当前本机 New Jazz 模式仍为同一段 Street / Jazz 动捕选出的 8 个八拍，总长约 33 秒。公共版为 8 个 Charleston 片段（4 个裁剪加 4 个镜像变体）。重排只改变现有动作的选择和顺序，没有新增动作素材，也没有接入生成式 AI。

“保存项目”会自动创建 `project.danceproj`，记录音乐片段、节拍、动作顺序、锁定、角色和镜头。保存后底部显示完整文件路径，保存按钮旁提供“打开目录”。“打开项目”默认定位当前项目目录；未打开项目时使用上次保存的目录，再回退到项目库。备份或移动时复制整个文件夹。

导入自己的歌曲后会明确提示“分析并打开”；完成后提示从底部“播放”开始。内置音乐的提示只在选择内置曲目时显示，避免导入后仍让人误以为在操作免费曲目。

核心回归覆盖真实两库连续 8 次重新编排、保存种子复现、锁定和时间槽保持、全部锁定、只有唯一安全路径以及失败后原状态恢复。实际应用验收新增直接调用按钮同一处理函数、比较动作 ID 必须改变的检查。结果见 [REARRANGEMENT_052_RESULTS.json](REARRANGEMENT_052_RESULTS.json)。

Windows ZIP 包含 `ChoreoStudio.exe`、离线 Python 和所有依赖，完整解压后运行。公开包不含私人 New Jazz 素材；个人学习版留在本机。关节修复沿用 0.5.1，构建重新执行单片段检查；连接复查的播放器源码与 8 个公共动作摘要必须与 0.5.1 相同才能复用其渲染证据。完整应用、镜头和便携检查使用当前 0.5.2 程序重新执行。
