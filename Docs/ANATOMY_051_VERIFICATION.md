# 0.5.1 反关节修复与复测

用户指出人物手部等部位反关节后，重新检查证实 0.5.0 存在真实错误。此前位移、接地、帧率和抽样画面的检查不足，旧版的动作质量结论已撤回。本次检查不依赖旧版的批准记录。

## 修复

SMPL-X 到 Unity 的坐标转换现在同时反射位置和旋转，修正坐标手性。使用原作者中性关节位置建立解剖方向，再从目标 Humanoid 的弯曲参考姿态校准肘、膝、手掌和指节，避免把接近伸直的中性肢体叉积误当作关节轴。

男女角色的骨骼名称相同，但局部轴不同。现分别烘焙两套轨道，运行时明确绑定角色；不再将女角色的局部旋转直接用于男角色。私有轨道 schema 2 包含角色标识，批准摘要同时覆盖两套轨道与过渡参数。

通过 Humanoid 求解约束范围后导出局部四元数，保留歌曲时钟采样接口。肘膝留出伸展余量；手腕限制屈伸和侧偏，手指限制张开和弯曲，并进行五帧零相位平滑。当前手势是针对内置模型的简化改编，不是原始动捕的无修改复制。公共 Charleston 的上身曲线也限制越界扭转，手指改为放松姿态。

原本连续的动作保留连续边界；非连续连接过渡由 0.5 拍延长到 0.6 拍，修复两处男角色的速度峰值。仍只保留每个舞种原先 20 条明确复查的有向连接。

## 检查范围与证据

- **单片段**：8 个个人学习动作、8 个公共 Charleston 动作，男女角色分别在 120 Hz 采样，共 32 个案例。检查全部 95 个 Humanoid 参数的有限值与范围，以及肘、膝、指节的带符号弯曲方向。
- **实际播放器连接**：使用交付的 `DancePlayback`，包括角色绑定、四元数插值、Playables 混合和接地。检查 56 条个人候选连接及 20 条公共已选连接，男女分别测试，共 152 个案例；只有正式选中的 80 个案例用于交付批准。候选全量通过数与正式连接通过数分别记录，不能混用。
- **画面复查**：逐张查看 16 张隔离手部近景板（每张含两个时刻、双手掌背共八格）、32 个最接近关节范围边界的全身帧，以及两种舞蹈的 80 张六帧连接板。未在这些修正版画面中看到旧版的明显反折。检查采用渲染帧和逐帧数值，没有声称观看了完整教学视频。
- **故障回归**：数学检查验证反射变换保持旋转对应关系；故意反向手腕、女轨道用于男角色，以及真实 0.5.0 坏轨道都必须被拒绝。旧 schema 1 批准保持未批准；新 schema 2 摘要错误时必须中止，并清除私有旧批准；恢复有效记录后两库各 8 个动作可用。

范围门槛为归一化绝对值不超过 1.02（含求解精度余量）。方向检查独立于归一化参数，拒绝超过 3° 的反向超伸，并限制最大弯曲。正式连接同时要求切点间隙小于 3 mm，120 Hz 相邻位置变化小于 50 mm、旋转变化小于 12°，蒙皮最低点不低于地面 5 mm。

## 运行与边界

本机个人版为 `Builds/PersonalWindows-0.5.1/ChoreoStudio.exe`，可用 `Scripts/run.ps1 -PersonalLearning -Demo` 载入暂停的组合，点击播放观看。默认启动继续恢复上次项目。GitHub 提供源代码与不含私人动作的 [0.5.1 公共 Windows 包](https://github.com/KSuperLiu/SongChoreography/releases/tag/v0.5.1)，不上传受限动作或个人程序。

完整应用通过命令行验收场景进行男女各 40 秒播放，测试三档速度、循环、定位、暂停恢复、锁定、替换和保存重开。后台模式静音，显式渲染生产舞台到同尺寸纹理，并保存实际舞台图；统计属于后台显式渲染测试，不冒充前台鼠标点击验收。软件时钟误差不包含扬声器延迟。

这些检查针对两个内置角色和明确批准的动作／连接。关节范围与可见帧检查不能证明任意模型、任意姿态都没有穿插，也不能代替专业舞蹈教师评价。FineDance 原始分类仍为 `Street / Jazz`；这里是个人 New Jazz／流行爵士练习改编。
