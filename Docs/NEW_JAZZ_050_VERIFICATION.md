# 0.5.0 个人学习版验收

日期：2026-11-02。Windows、Unity 2022.3.62f3、GTX 1050 Ti。受限动作、姿态数组、截图和个人版程序只保留在本机；本文件记录本项目的测试方法与结果。

测试汇总与被测程序集 SHA-256 见 [NEW_JAZZ_050_RESULTS.json](NEW_JAZZ_050_RESULTS.json)，只包含本项目生成的测试统计。

## 动作与连接

FineDance `001` 原作者标签为 `Street / Jazz`。从约 115 BPM 的源动作中选取 24.2121 秒起的连续 64 拍，分为 8 个不同的八拍片段，总长约 33.40 秒。作为 New Jazz／流行爵士练习改编，保留原始来源标签；不是传统 Charleston 的改名或程序摆动。没有专业舞蹈教师认证，也不是完整的多曲目 New Jazz 素材库。

52 关节四元数轨道避免复杂手腕／脚踝在 Humanoid muscle 分解时翻转。原本连续的 7 条连接保留源运动；其他连接使用经过复查的半拍过渡。当前只支持两个经过验证、共用骨骼层级的内置角色。

- 两个角色各 8 个完整动作：16 项采样检查通过，16 张完整八拍画面板经 Codex 逐图复查。
- 56 条非自连接 × 两个角色，共 112 项候选检查；74 项通过。没有批准全部候选。
- 选定 20 条在两个人物上均通过的连接；40 张六帧连接画面板经 Codex 逐图复查。
- 批准后再次测试正式连接：40/40 通过。地面最低网格保持约 +8 mm；连接瞬间位置差小于 3 mm、120 Hz 采样的最大帧间角小于 12°、位置差小于 50 mm。
- 动作批准同时绑定曲线、关节轨道和源数据 SHA-256；公开批准清单只含本项目编写的名称、摘要、说明与连接，不含动作或画面。

采样阈值不能检测全部滑脚、身体穿插或教学难度，画面板也不是全帧专家验收。自动生成可按节拍重定时和在批准图中编排；不声称能够识别音乐乐句，或对任意音乐给出专业编舞。

## 功能回归

核心 C# 检查 43 项全部通过：种子复现、锁定、未来锁定约束、替换保时长、节拍相位、项目保存、路径约束、个人库来源与连接边界、公开构建隔离。

Python 8 组测试全部通过：三个不同速度的节拍音轨、MP3 与保留音高慢放、静音／短片段／取消／非法请求，以及 6D 旋转约定、退化轴、非有限值、源标签、覆盖范围、个人使用标记、拒绝 NPY pickle 数据。

实际播放器执行两个人物各 40 秒编舞，检查三档速度的循环、暂停、定位恢复，替换和锁定再生成、首段计数相位、完整项目恢复。显示测试曲目保留原 CC BY 4.0 授名，没有把源动捕对应的商业歌曲放进应用。

复查发现并修复完整八拍停止时回到首帧的问题；新增实际骨骼位置检查，要求结束前后差小于 3 mm。发型验收也改为沿头部方向测量真实网格与头骨顶点，避免仰头时世界包围盒空角造成误报；阈值保持 5～100 mm，实测女角色约 85 mm、男角色约 45 mm。

最终个人版 26 项成品检查全部通过。GTX 1050 Ti、1920×1080、6,250 个播放采样帧，平均帧耗时约 16.67 ms，95 百分位约 16.67 ms（约 60 FPS）；软件音频时钟最大差约 42.67 ms，小于 50 ms 目标，不含扬声器／设备延迟。测试生成 40 秒、5 种不同动作的组合，7 个时间槽可替换且不改时长；三档速度累计检查 14 次循环。两角色七镜头 57 项全部通过，包括自由旋转／平移／缩放、构图恢复与镜像。

个人版复制到中文及空格路径后，子进程移除系统 Python 路径和分析器环境覆盖，内置引擎实际完成导入、慢放、循环与保存恢复；原目录与复制目录的程序集 SHA-256 一致。

公开构建的 Charleston 回归：25 项完整成品检查、57 项角色镜头及便携导入全部通过；1080p 平均约 16.67 ms，软件音频时钟最大差约 21.33 ms。首轮公共回归窗口在报告写入前提前关闭，没有计作通过；重跑得到完整通过报告。公共构建快照中个人动作、个人原始数据与个人署名目录均为 0。

## 数据隔离

已实际将一条批准摘要改为错误值：Unity 准备失败、退出码 1，并清除所有旧批准（0 个仍批准），防止新数据继承旧批准。测试在隔离缓存中进行，随后恢复正确输入。
