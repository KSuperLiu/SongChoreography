# 快速使用

1. 完整解压发布包，双击 `ChoreoStudio.exe`。点击“一键演示”，立即播放 40 秒 Charleston 练习组合。
2. 左侧三首免费曲目均可“试听”或“使用”。“使用”会创建独立练习项目。
3. 导入 WAV／MP3，填写起点和 30～60 秒长度，再点击“分析并打开”。本机后台分析可取消，失败保留原项目，源音频不会被修改。
4. 首次跟学建议选 0.5× 或 0.75×。空格播放／暂停，左右方向键定位；输入框编辑时不会触发快捷键。
5. 画面下方切换正面、背面、左右侧、上身、脚步和自由镜头。左键旋转，右键／中键平移，滚轮缩放，双击复位。“镜头”页可直接设置视野、距离、角度和平移，也能改为左键平移。
6. “镜像”翻转画面，上方切换男女角色；音乐位置保持。
7. “节拍”页校正 BPM、首拍相对片段的秒数、首拍对应的八拍计数。计数设为 4 时，首段从动作第 4 拍开始，跳完 4～8 后进入下一组八拍；调整会真正改变分组，受影响的锁定需先解除。首拍范围 0～3 秒，长前奏请调整截取起点。自动检测不等于乐句识别，请试听后校正。旧项目按原编排恢复，重新生成后采用新分组规则。
8. 点击右侧片段定位，旁边圆圈用于锁定。下方替换动作满足前后连接约束；需先解锁才能替换。“换一版”保留锁定片段。
9. 底部填写循环起终点并点击“设置区间”，从起点反复练习。
10. 点击“保存项目”；退出也会保存有效项目，下次启动暂停恢复。“打开项目”选择 `project.danceproj`。备份或移动时复制整个项目目录。

## 常见情况

- 检测不到可靠节拍：手动填写 BPM、首拍和计数再生成。静音、氛围音乐、速度变化大的歌曲可能不适合自动编排。
- 校正或重新生成失败：查看底部提示，解除与新时间格或连接冲突的锁定后再试，原编排保留。
- 文件读取失败：确认文件存在且未损坏，选择有效的 WAV／MP3。
- 看不到完整角色：点击“复位”。上身和脚步镜头本来就是局部特写。
- 没有声音：点击“播放”或“一键演示”，检查 Windows 音量混合器中的应用音量及输出设备。
- 找不到分析引擎：完整解压并保留 `Runtime/Python`，正常使用无需填写自定义路径。

当前舞种为 Charleston 八拍练习改编。New Jazz 素材仍待补齐；来源与修改说明可在“资源署名”和随包文件中查看。
