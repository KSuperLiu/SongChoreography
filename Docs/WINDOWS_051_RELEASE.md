# 0.5.1 Windows 公共发行包

下载 ZIP 并完整解压，运行 `ChoreoStudio.exe`。EXE 依赖同目录的 `ChoreoStudio_Data`、`Runtime`、`MonoBleedingEdge` 和 DLL，不能只复制单个 EXE。无需安装 Unity 或系统 Python，准备好的包可离线运行。

本版包含两个角色、三首免费测试音乐、八个 Charleston 练习片段、七种镜头、镜像、三档保留音高慢放、音乐导入、节拍校正、循环、替换、锁定和项目保存恢复。点击“一键演示”即可观看 40 秒组合。

0.5.1 限制了公共舞蹈的异常上身扭转，调整放松手势，增加全身关节范围和肘膝、指节弯曲方向检查。两个人物分别通过 120 Hz 单动作检查（共 16 个案例），正式连接分别复测（共 40 个案例）。随包的连接图是实际 DancePlayback 采样的渲染帧板，技术与 Codex 画面复查不代表专业舞蹈教师认证。

最终公共程序完成 27 项完整播放及编辑检查、57 项角色镜头检查。GTX 1050 Ti 下，以 1920×1080 应用窗口、1240×694 生产舞台纹理，在静音后台显式渲染 6248 帧，平均帧耗时约 16.67 ms，软件音频时钟最大差约 42.66 ms。该统计描述后台渲染测试，不冒充前台鼠标点击或扬声器延迟测试。

完整发布目录复制到中文和含空格路径、移除子进程的系统 Python PATH 后，内置分析器导入、保存重开和程序集哈希比对通过。`PACKAGE.json` 记录包内文件的长度及 SHA-256，发行页同时提供 ZIP 校验值与校验报告。

公开包展示 **Charleston**。用户本机 New Jazz／流行爵士学习改编使用的 FineDance 动作受第三方分发限制，不包含在本包、GitHub 源码或上传附件中。两者使用相同的音乐、编辑和播放应用；源素材与改编的细节见第三方说明和关节修复验证。
