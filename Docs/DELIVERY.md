## 完成顺序

1. 解决真实舞蹈素材及连续衔接；先做两个片段，再扩充八个并组成完整演示。
2. 根据真实舞蹈调整角色、接地、根位移、镜头与舞台。
3. 打通便携分析环境，完善导入、校正、编辑、保存和错误恢复。
4. 打磨一键演示与首次体验，移除演示流程中的开发配置负担。
5. 做最终包的真实交互、画面、同步、编辑、稳定性与性能验收，修复失败项后重测。
6. 交付可直接运行的发布包、演示、使用说明与验收报告。

## 诚实验收规则

- 不将程序诊断动作或未经风格确认的其他舞种标成 New Jazz。
- 真实 New Jazz 如无法获得合适的免费授权素材，保留明确缺口，同时必须先完成有准确舞种标注的真实舞蹈演示，不能继续以静态站立和诊断动作作为展示成品。
- 自动测试、人工画面复查与实际鼠标操作分别记录；未测试的项目不写“已通过”。
- 首版维持本地、单角色、稳定四拍音乐、30～60 秒片段；不扩展云服务、视频导出、摄像头评分或生成式模型，优先完成现有闭环。
