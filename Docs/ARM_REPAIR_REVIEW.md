# 手臂适配修复与 Unity 运行复查

2026-11-03。当前 Tripo 人物继续使用原模型，修复了手掌、手指和前臂与身体的适配，并恢复 **8 种基础练习动作、10 条有向连接**。原先 Snake 穿入腰胯的区间已重新检查。该推荐保留 Hip Hop 来源，供 New Jazz 基础练习，未作专业舞种认证。

本轮实际在主 Unity 2022.3.62f3 的 Play Mode 播放原创 **100 BPM、38.4 秒**伴奏，使用 8 种不同动作，完成原速、0.75×、0.5× 和音乐区间循环；运行异常 **0**。本轮没有打包，没有付费 API 请求。

## 原因和修复

已确认的原因是人物体型与 Humanoid 动作的适配，以及原播放程序缺少身体体积避让。有效 Avatar、能播放和拍点正确都不足以证明没有穿插。人物映射有效，左右臂长基本对称，CPU 蒙皮与 Unity BakeMesh 的最大顶点差约 0.00000036 米；没有发现必须重做人物的证据。当前 Mixamo FBX 不含源人物皮肤，不能据此判断源角色本来是否穿模。

播放时在动作混合后，以当前人物网格拟合的身体包络修正手掌和前臂。双骨骼 IK 保持臂长，保留原手腕世界朝向；腿部与躯干动作保持原轨迹。提前生成的连续修正轨迹平滑避让变化，并保留重定向在接近伸直关节时的扭转补偿。暂停、拖动和慢放都按相同时间位置取样。动作预览循环和音乐区间循环使用短过渡，避免直接跳回起点。

人物和动画源文件哈希绑定修正轨迹。人物更新后，旧轨迹不会套到新模型；批量生成中断会保留之前完整的轨迹库。人物网格导入时开启 Read/Write，实际运行能够读取蒙皮数据。

## 已验证范围

| 检查 | 帧数 | 网格采样点 | 检出超过 2 毫米的穿入帧 |
|---|---:|---:|---:|

| 8 段映射到 100 BPM，60 Hz | 2312 | 5,650,528 | 0 |
| 10 条连接与 8 个预览循环，60 Hz | 1438 | 3,514,472 | 0 |

碰撞复查使用 Unity 原生 BakeMesh 后的手／手指／前臂网格采样，以及按骨骼权重选出的实际身体三角形；与运行时包络求解器分别实现。密集检查覆盖全部被选中的手和前臂顶点，身体内外采用射线和最近表面法向判定。2 毫米是本轮检测容差。这不是所有身体部位、任意模型或任意动作的无碰撞认证。

Snake 的额外手掌相邻帧位移由约 8.9 厘米降至 5.2 厘米，额外手肘位移由约 10.7 厘米降至 4.7 厘米，均按 30 Hz 源时间采样。暂停重复取样误差和跨动作拖动返回误差为 0；骨长误差低于 0.001 毫米，手腕朝向和腿部相对姿势误差为 0。查看了 8 段的正面、侧面姿态图，并通过实际播放检查；位移预算与视觉复查一起使用，不把单一数值当成自然度证明。

完整原片另外修复了两处平滑扭转补偿的问题；已批准的 8 段裁剪范围轨迹哈希与密集检查时完全相同，相关记录保存在验证 JSON 中。

Play Mode 共记录 465 个时间采样，实际人物手／前臂网格抽查 234 帧、70,434 点，未检出超过容差的穿入。音乐区间循环观察到 6 次回绕，回绕瞬间最大手掌位移 1.07 厘米，6 次循环过渡结束时最大手掌位移 1.58 厘米。音频时间误差、序列与各阶段记录见验证 JSON；Editor 采样时序误差不是声卡延迟测量。
