## 实际交互与验证方式

0.3 已用真实鼠标检查内置音乐使用／试听、原生 WAV／MP3 文件选择器、七种镜头、拖动缩放、角色切换、镜像、设置、署名和暂停。0.4 正常启动画面、布局与新动作实际渲染已查看。

2026-11-02，用户确认桌面空闲后，已实际点击最终 0.4.0 发布程序的一键演示，确认 Funkorama 打开并播放、角色动作和八拍计数推进；点击暂停后停在约 23.9 秒。随后进入 BPM 输入框，按左方向键及空格，音乐仍保持暂停且位置不变，输入文字和应用校正正常。实际点击切换男角色、背面镜头、镜像与 0.75×，暂停位置保持不变。此前的输入保护提示来自桌面争用，没有绕过保护。

此次实际点击范围不包含重做全部编辑与保存控件；真实动作替换、锁定、重新生成和完整保存重开由最终包的自动运行验收验证。0.4.1进一步修复首拍计数对真实八拍分组的影响：计数4的首段为5拍，起始姿势与完整动作第4拍的实际骨骼位置差为0，接入下一段的位置差约0.343 mm，相位保存重开通过。新构建24项完整运行检查、57项角色镜头和便携导入均通过。

## 准确边界

这是技术和 Codex 渲染画面复查，没有舞蹈教师认证或真人学习效果评估。New Jazz 素材仍为零，当前成品提供 Charleston 练习改编；不冒充 New Jazz。

软件 DSP／音频采样时钟差不等于扬声器实体音画延迟，本次没有测量外部硬件延迟。默认验证稳定四拍、30～60 秒单段、单角色；没有验证整首歌、变拍、多角色、专业教学或视频输出。
